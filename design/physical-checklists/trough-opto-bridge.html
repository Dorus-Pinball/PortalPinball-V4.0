Trough Opto Bridge — ATmega328P Build Sheet

Bench build for a standalone ATmega328P-PU that reads the Stern trough opto board (520-7001-00A) over its VCC/RCK/SCK/MISO/GND connector and re-presents the 7 opto channels as clean switch signals for OPP — replacing the fragile hand-soldered per-leg taps that caused the wiring damage logged in commit 859a6b9.

Program the chip

Do this on every chip pulled from stock — don't assume factory-default fuses.

  1. Host the ArduinoISP shield on the Uno (or Duemilanove); load the ArduinoISP sketch onto it.
  2. In the Arduino IDE, select board "ATmega328 on a breadboard (8 MHz internal clock)", with the ISP shield as programmer.
  3. Run Burn Bootloader — this sets the fuses to the internal RC oscillator, so no external crystal is ever needed.

Firmware logic

  1. On boot: configure SPI as master (SS, MOSI, SCK as outputs per Section 2).
  2. To read a frame: pulse RCK low→high to latch the 8 parallel opto bits.
  3. Clock one byte via SPI (write 0x00 to SPDR, wait for SPIF) — result in SPDR has one bit per channel, MSB first.
  4. Drive the 7 mirror pins from those bits — confirm polarity by hand (especially s-trough-jam, which reads active = clear path, not jammed) before trusting it.
Board identity: Stern 520-7001-00A "Trough Serial Opto Receiver" — U1 NXP 74HCT165D (8-bit PISO shift register), U2 NXP 74HC540D (octal buffer). Connector silkscreened VCC/RCK/SCK/MISO/GND. See TODO.md and commit 859a6b9 for the original wiring-damage report this build replaces.
