00

Before power-on

Visual/mechanical pass with the machine unplugged. Catches the cheap failures before anything gets energized.

No loose wire ends, pinched harnesses, or connectors sitting half-seated on any of the three OPP chains (COM4/COM5 Cobra, COM6 PSOC ×4)
Trough holds exactly 4 balls (matches balls_installed: 4 in hardware-basic.yaml) — add/remove before powering on, not after
Flipper mechs: dual-wound coils seated, mechanical EOS interrupter moves freely by hand, no binding at end of stroke
Drop target bank (3 targets) resets freely by hand, no snagging in the guide rails
Sling and popbumper rubber in good condition, not so loose/tight it changes the expected pulse strength

Power-on & board scan

Run ../.venv/Scripts/mpf (no -X) from machinefolder/ — this is the real opp platform, not smart_virtual. Compare the scan MPF prints against the pasted reference in hardware-basic.yaml (lines 12–44).

COM4 (chain 0), COM5 (chain 1), COM6 (chain 2) all enumerate — no "port not found" / timeout errors
Ports seen:
Chain 2 shows all 4 PSOC boards (0x20, 0x21, 0x22, 0x23) — a missing board here silently drops a quarter of the switches/coils
Firmware versions match the reference scan (0x2040000 on chain 0/1, 0x1000004 on chain 2 boards)
MPF boots to attract mode with no config warnings/errors in the console
If any port/board differs from the reference scan — USB re-enumeration drift — update the comment block in hardware-basic.yaml before moving on, so it stays trustworthy
